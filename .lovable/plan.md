
# תוכנית פיתוח: שדרוג מקיף למערכת החיפוש

## סקירה כללית
הוספת 8 פיצ'רים חדשים לשיפור חווית השימוש, נגישות ופונקציונליות המערכת.

---

## 1. מצב כהה (Dark Mode) 🌙

### מה זה?
אפשרות להחליף בין מצב בהיר לכהה עם שמירת ההעדפה

### מה יתווסף:
- כפתור מתג בהדר לשינוי מצב
- שמירת ההעדפה ב-localStorage
- זיהוי אוטומטי של העדפת המערכת
- אנימציית מעבר חלקה בין המצבים

### קבצים שישתנו:
- `src/index.css` - הגדרות צבעי Dark Mode (כבר קיימות חלקית)
- `src/components/Header.tsx` - הוספת כפתור מתג
- `src/App.tsx` - הוספת ThemeProvider

---

## 2. שדרוג מערכת הסימניות 📌

### מה זה?
שיפור מערכת הסימניות הקיימת עם יכולות נוספות

### מה יתווסף:
- שמירה ל-localStorage (persistency)
- ייצוא סימניות לקובץ JSON
- ייבוא סימניות
- סינון וחיפוש בתוך הסימניות
- תצוגה נפרדת של כל הסימניות

### קבצים שישתנו:
- `src/components/ResultBookmarks.tsx` - שדרוג הקומפוננטה
- `src/hooks/useBookmarks.ts` - Hook חדש לניהול סימניות

---

## 3. קיצורי מקלדת מתקדמים ⌨️

### מה זה?
מערכת קיצורים מורחבת עם ניווט מהיר ומדריך

### קיצורים חדשים:
| קיצור | פעולה |
|--------|--------|
| `↑/↓` | ניווט בין תוצאות |
| `Enter` | קפיצה לתוצאה נבחרת |
| `Ctrl+N` | תוצאה הבאה |
| `Ctrl+P` | תוצאה קודמת |
| `Escape` | סגור חלון/ביטול |
| `?` | פתח מדריך קיצורים |

### מה יתווסף:
- Dialog עם כל הקיצורים
- ניווט מקלדת בתוך תוצאות
- הדגשת התוצאה הפעילה

### קבצים שישתנו:
- `src/hooks/useKeyboardShortcuts.ts` - הרחבת הפונקציונליות
- `src/components/KeyboardShortcutsHelp.tsx` - קומפוננטה חדשה
- `src/pages/Index.tsx` - אינטגרציה

## 4. תבניות חיפוש נוספות 📋

### תבניות חדשות:
- **חיפוש בסוגריים** - מציאת טקסט בסוגריים
- **מילים נרדפות** - חיפוש עם מילים דומות
- **שאלות ותשובות** - זיהוי דפוסי Q&A

- **הגדרות והסברים** - זיהוי דפוסי "כלומר", "דהיינו"
- **ציטוטים** - זיהוי טקסט במרכאות

### קבצים שישתנו:
- `src/components/SearchTemplates.tsx` - הוספת תבניות
